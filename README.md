##  Project Overview
An interactive Power BI dashboard designed to analyze e-commerce sales performance. This project transforms raw transaction data into actionable business insights, helping stakeholders track revenue trends, profitability, and regional growth.

##  Tech Stack & Skills Demonstrated
* **Tools Used:** Power BI, Power Query, Excel
* **Core Skills:** Data Cleaning (ETL), Data Modeling, Data Visualization, Business Storytelling
* **Key DAX Measures Created:** `Total Sales`, `Total Profit`, `Profit Margin %`, and `Sales YTD`.

##  Key Dashboard Features & Insights
* **Revenue Tracking:** Top-level KPI cards for instant visibility into Sales, Profit, and YTD performance.
* **Trend Analysis:** Monthly sales trend visualization to identify seasonal peaks and drops.
* **Category & Region Performance:** Clear breakdown of high-performing product categories and most profitable geographical regions.
* **Payment Mode Distribution:** Donut chart analysis showing customer payment preferences (Credit Card, UPI, Cash, etc.).
